# Engineering Knowledge Hub

Персональная лаборатория для backend-инженера. В Learning Roadmap есть 106 экзаменационных тем и 318 проверяемых навыков. Выберите PostgreSQL → Transactions → Isolation Levels → Repeatable Read, пройдите самопроверку и добавьте собственный пример. Граф, заметки, интервальные повторения, интервью, английская практика, эксперименты и черновики публикаций доступны в том же приложении.

## Хостинг и архитектура

[Открыть GitHub Pages](https://tantarin.github.io/engineering-knowledge-hub/)

Next.js с TypeScript генерирует статические HTML, CSS и JS через output: export. Отдельный процесс Node и серверная база на хостинге не нужны. В браузере Dexie работает с IndexedDB. MiniSearch индексирует текст заметок и полей рабочей области. ts-fsrs рассчитывает расписание карточек. Переходы к заметкам и программе используют URL-фрагменты, например [тема Repeatable Read](https://tantarin.github.io/engineering-knowledge-hub/#roadmap/data-rr). При перезагрузке браузер запрашивает существующий index.html.

В предыдущей локальной версии SQLite и Next.js API Routes обслуживали CRUD, файлы и поиск. В статической версии эти операции выполняет единый браузерный адаптер. Код SQLite сохранён для офлайн-конвертации существующего рабочего пространства.

## Локальный запуск

Нужен Node.js 24 или 26 и npm. В корне проекта:

```sh
npm ci
npm test
npm run build
npm start
```

Откройте http://127.0.0.1:3184/. Для разработки используйте npm run dev. Для проверки именно пути проекта GitHub Pages:

```sh
PAGES_BASE_PATH=/engineering-knowledge-hub npm run build
PAGES_BASE_PATH=/engineering-knowledge-hub npm start
```

В этом случае откройте http://127.0.0.1:3184/engineering-knowledge-hub/. Переменную для production передаёт Actions. Файл .env.example содержит пример.

## GitHub Pages

1. Используйте публичный репозиторий и основную ветку main. GitHub Free поддерживает Pages для публичных репозиториев.
2. В Settings → Pages → Build and deployment → Source выберите GitHub Actions.
3. Отправьте изменения в main. Workflow в .github/workflows/deploy.yml установит зависимости через npm ci, проверит данные программы, выполнит тесты, соберёт out/ с правильным basePath и загрузит только эту папку как Pages artifact.
4. Адрес публикации доступен в Actions → Publish Knowledge Hub → deploy. При необходимости workflow можно запустить вручную. Для пользовательского сайта USERNAME.github.io базовый путь будет пустым.

Права чтения содержимого использует сборка. Права pages:write и id-token:write получает только задача деплоя. [Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Программа и прогресс

Исходная программа хранится в src/curriculum-*.json. Сборщик scripts/syllabus.mjs проверяет структуру и создаёт public/syllabus.json. Каждая тема имеет постоянный ключ. Стабильные идентификаторы существующих навыков сохраняйте при редактировании: для перестановки или вставки в середину задавайте явные объекты с id и text. Новые строковые навыки добавляйте в конец. У каждого вопроса есть эталон, критерии и первоисточники. Официальные сведения Revolut вынесены в src/revolut-context.json.

При первом запуске темы загружаются в IndexedDB. При изменении версии syllabus обновляются базовые темы, сохраняются ручные правки, созданные темы, скрытые темы и история. Схемы v1 и v2 определены в src/browser-db.mjs. Обновление до v2 добавляет таблицы программы без пересоздания старых. Имя базы зависит от пути приложения, а не от номера сборки.

Освоенная тема требует двух отметок для каждого навыка — объяснение без подсказки и применение на практике. Дата проверки обновляется при явной проверке навыка или отметке соответствующей способности. Прохождение экзамена сохраняет ответ и самооценку отдельно. Частичный или неверный последний ответ помещает тему в повторение. Фильтр также учитывает ручные отметки повторения. Дневная история фиксирует реальный числитель и знаменатель. Скрытые темы исключены из расчёта.

## Личные материалы и резервные копии

В «Данные и копии» доступны Export All Data, Import Data, Export Progress, Reset Progress и экспорт читаемых Markdown с изображениями. Основной переносимый формат — JSON со схемой версии 2. Полный файл включает вложения, связи, пользовательские темы, вопросы, расписание и историю. Для переноса на другой компьютер экспортируйте файл и импортируйте его в другом браузере. Для отдельного переноса прогресса карточек и заметок на принимающей стороне уже должны быть соответствующие исходные записи. Если хотите перенести их вместе, используйте полный экспорт.

Импорт проходит в одной транзакции. По умолчанию отсутствующие записи добавляются, а конфликтующие существующие версии сохраняются. Для восстановления более свежих оценок из файла включите замену совпадающих ID и подтвердите действие. Ошибка формата или целостности отменяет транзакцию. При Reset Progress приложение предлагает подтверждение и инициирует загрузку копии прогресса. Тексты заметок и созданные темы сохраняются.

Для переноса с локальной версии SQLite закройте редактор и выполните:

```sh
node scripts/convert-private.mjs
```

Файл data/engineering-hub-personal.json создаётся вне публичной директории. Откройте готовый сайт и импортируйте файл через «Данные и копии». Оригинал SQLite и исходные файлы Obsidian доступны как отдельные копии. Офлайн-импорт дополнительной папки Markdown для последующей конвертации выполняется через node src/import-vault.mjs "/путь/к/папке".

## Границы бесплатной версии

Хранилище привязано к браузерному профилю, адресу сайта и пути проекта. Смена устройства, профиля или адреса требует ручного переноса. Очистка данных сайта удаляет IndexedDB. Режим инкогнито и квоты браузера ограничивают хранение. Резервные копии содержат личные тексты и изображения в открытом виде. GitHub получает статические запросы ресурсов сайта. Формы работают локально. Разные Pages-проекты одного владельца могут иметь общий браузерный origin, поэтому доверяйте коду, который размещается на этом домене.

Markdown обрабатывается без сырого HTML; внешние изображения автоматически не загружаются. Вложения проверяются по сигнатуре, размер ограничен 5 МБ. Формулы и Mermaid рендерятся локально. Playground хранит фрагменты и результаты экспериментов. English Lab поддерживает письменную практику. AI-оценка, запись голоса и запуск пользовательского кода остаются возможными расширениями. Публикация контента выполняется пользователем вручную.

Для будущей синхронизации можно добавить отдельный авторизованный сервис, журнал изменений с устойчивыми ID, удалениями и версиями, разрешение конфликтов и синхронизацию вложений. Секреты должны храниться на стороне этого сервиса. IndexedDB продолжит обслуживать работу при отсутствии подключения после загрузки интерфейса.

## Управление

Cmd/Ctrl + K — поиск, Cmd/Ctrl + Alt + N — новая заметка, Escape — закрыть диалог. Understand, Practice, Explain, Recall, Connections, Sources и Publish доступны в рабочей области темы базы знаний. Новые карточки из заметок требуют явного подтверждения. Тёмная тема и сворачивание меню доступны в верхней панели.
